# 行为与训练

这里记录小咪的行为模式、情绪线索、训练方法和结果。核心原则是先观察，再假设，再做小范围调整。

## 主要文件

- `behavior_observations.md`：行为观察总表。
- `training_plan.md`：训练目标、咬手/玩耍边界和可执行步骤。
- `litter_box.md`：猫砂盆使用。
- `stress_triggers.md`：压力源和舒缓方式。
- `socialization.md`：社会化和访客、外出、洗澡剪指甲等适应。

尚未出现具体事件的抓挠问题不单独建空表；资源配置记录在 `06_environment_supplies/enrichment_play.md`，实际事件出现后写入 `behavior_observations.md`。
